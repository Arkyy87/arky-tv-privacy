Política de privacidad de ARKY TV

Última actualización: 5 de octubre de 2026

2. Qué es ARKY TV

ARKY TV es un reproductor multimedia para Android y Android TV. Permite al usuario configurar un servicio IPTV propio o de terceros y reproducir el contenido que ese servicio proporciona.

ARKY TV no proporciona por sí misma canales, películas, series ni listas IPTV. El usuario es responsable de disponer de los derechos o autorización necesarios para acceder al contenido configurado.

3. Datos que introduce el usuario

Al configurar un servicio Xtream, el usuario puede introducir la dirección del servidor, nombre de usuario y contraseña. Se utilizan para autenticar al usuario y solicitar catálogos y contenido al servicio configurado.

4. Almacenamiento de credenciales

Las credenciales guardadas localmente se protegen mediante Android Keystore y cifrado AES-GCM. ARKY TV no vende las credenciales ni las utiliza para publicidad o analítica.

5. Datos almacenados en el dispositivo

ARKY TV puede almacenar localmente credenciales cifradas, favoritos, contenido visto recientemente, progreso y «Continuar viendo», categorías ocultas y preferencias, cachés de categorías y catálogo, imágenes y archivos temporales relacionados con el catálogo. Las cachés nuevas están separadas por identidad de cuenta.

6. Eliminación de datos

ARKY TV dispone de Eliminar datos en Ajustes. Al confirmarlo, elimina los datos locales atribuibles a la cuenta seleccionada, incluidas credenciales, favoritos, historial reciente, progreso, preferencias y cachés identificables.

Los datos antiguos cuyo propietario no pueda determinarse de forma segura no se eliminan mediante un borrado global. Cerrar sesión es independiente de Eliminar datos.

7. Datos enviados a servicios externos

Cuando el usuario configura un proveedor IPTV, ARKY TV puede enviar al servidor configurado credenciales y solicitudes necesarias para autenticación, categorías, canales, películas, series, episodios, información de contenido y reproducción. Algunas URLs de reproducción pueden incluir las credenciales cuando así lo exige el formato del servicio.

Importante sobre HTTP: algunos servicios IPTV pueden proporcionar únicamente direcciones HTTP. HTTP no ofrece el mismo cifrado en tránsito que HTTPS. ARKY TV no convierte automáticamente HTTP en HTTPS porque eso no garantiza que el servidor admita HTTPS. Cuando sea posible, se recomienda utilizar proveedores que ofrezcan HTTPS.

8. Imágenes y recursos

Las carátulas, imágenes, recursos HLS y otras URLs pueden proceder del catálogo o proveedor configurado. Las URLs pueden apuntar a servidores externos cuyas prácticas de privacidad no controla ARKY TV.

9. DNS y conexiones de red

La aplicación puede utilizar resolutores DNS para resolver dominios necesarios. Las conexiones de red pueden implicar información técnica normal, como la dirección IP. ARKY TV no utiliza estas conexiones para crear perfiles publicitarios.

10. Vídeos locales

La función «Vídeos locales» utiliza el selector del sistema Android para que el usuario elija un archivo. El vídeo seleccionado se reproduce localmente y no se sube al desarrollador.

11. Publicidad y analítica

La aplicación no integra actualmente servicios propios de publicidad, Firebase Analytics ni Crashlytics. ARKY TV no vende datos personales ni sensibles.

12. Registros técnicos

La aplicación puede generar registros técnicos para diagnosticar errores. Se aplican medidas de sanitización para evitar la exposición de credenciales y otros datos sensibles. El sistema Android y bibliotecas de terceros pueden generar sus propios registros.

13. Terceros

ARKY TV utiliza bibliotecas necesarias para sus funciones, incluyendo AndroidX, Media3, Glide, OkHttp y Kotlin/coroutines. El proveedor IPTV elegido por el usuario es un tercero independiente y se rige por su propia política de privacidad.

14. Seguridad

ARKY TV protege las credenciales almacenadas mediante Android Keystore y cifrado. Las conexiones HTTPS mantienen validación TLS y de hostname. Ningún sistema puede garantizar seguridad absoluta.

15. Conservación

Los datos locales se conservan mientras sean necesarios para las funciones de la aplicación o hasta que el usuario los elimine. Las cachés pueden eliminarse o sustituirse durante el funcionamiento normal.

16. Menores

ARKY TV no está diseñada específicamente para recopilar datos de menores y no solicita deliberadamente datos de menores para publicidad.

17. Cambios

Esta política puede actualizarse cuando cambien las funciones, el tratamiento de datos o los requisitos aplicables. La fecha de actualización aparecerá al principio.
